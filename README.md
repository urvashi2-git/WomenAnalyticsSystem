# Women Analytics System

**Turning Women's Safety Data into Meaningful Insights.**

## 📌 About the Project

Women Analytics System is a web-based analytics platform designed to collect, organize, analyze, and visualize data related to women's safety.

The platform aims to transform submitted safety reports into meaningful insights through interactive dashboards and data visualization, helping identify patterns, understand safety concerns, and support data-driven decision-making.

This project is developed as a college minor project with the vision of building a technology-driven platform that can contribute to a safer society.

## 🎯 Objectives

- Provide a platform for submitting women's safety-related reports.
- Organize and manage submitted reports.
- Analyze safety-related data.
- Visualize trends and patterns through interactive dashboards.
- Support informed decision-making through data analytics.
- Explore opportunities for future collaboration with government organizations.

## ✨ Key Features

- **Home Page:** Introduction to the platform and its purpose.
- **Report Submission:** Interface for submitting women's safety-related reports.
- **Admin Dashboard:** Centralized interface for managing submitted reports.
- **Data Visualization:** Graphical representation of safety-related statistics.
- **Analytics:** Identification of patterns and trends using collected data.
- **User-Friendly Interface:** Simple and accessible web design.

## ⚙️ Installation and Setup

### Prerequisites

- Java Development Kit (JDK)
- Visual Studio Code
- Git
- MySQL Server
- Web Browser

### Steps to Run the Project

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Open the project folder**

```bash
cd women-safety-analytics
```

**3. Configure the database**

- Install and start MySQL Server.
- Create the required database.
- Configure database credentials in `application.properties`.

**4. Run the application**

On Windows PowerShell:

```bash
.\mvnw.cmd spring-boot:run
```

**5. Open the application**

Visit:

```text
http://localhost:8080
```
